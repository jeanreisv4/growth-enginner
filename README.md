# growth-enginner

Skills e automações de growth engineering para o Claude Code.

## Conteúdo

| Pasta | O que é |
|---|---|
| [`sprint-growth/`](sprint-growth/) | Sprint growth do cliente: audita a jornada inteira, do tráfego à venda (Google Ads, Meta, GTM, GA4, página, CRM, comercial), acha a restrição pela Teoria das Restrições e entrega o plano 5W1H priorizado por impacto em receita, com as correções executadas pelas MCPs. |
| [`projecao-breakeven/`](projecao-breakeven/) | Transforma a planilha de indicadores do cliente numa projeção de breakeven: veredito de realismo, benchmarks verificados com fonte e planilha .xlsx pronta para apresentar. |
| [`checkin-ropre/`](checkin-ropre/) | Transforma os dados brutos do cliente num check-in ROPRE (deck e documento), com a regra de atribuição declarada e o que não foi medido escrito na cara. |
| [`tracking-web-and-capi/`](tracking-web-and-capi/) | Tracking web e Conversions API. |

Como as skills se encadeiam: o **check-in ROPRE** acompanha o mês; a **sprint growth** diagnostica e prioriza;
a **projeção de breakeven** diz se o plano fecha a conta; o **tracking web e CAPI** implementa a medição que a
sprint aponta como quebrada.

Nenhuma pasta traz dado de cliente: cada skill gera sua cópia pública com o cliente trocado pelo segmento.
